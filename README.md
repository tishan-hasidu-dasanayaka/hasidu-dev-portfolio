## 🚀 About the Project

**HASIDU.Dev** is my personal developer portfolio, built to showcase my work, technical interests, and continuous learning journey.

The goal is simple: turn ideas into useful digital experiences, explore new technologies, and keep improving through real projects.

The portfolio features a modern dark interface, subtle animations, interactive project cards, and a responsive layout designed for different screen sizes.

## ✨ Features

- 🌌 **Modern UI** — A clean dark theme with subtle neon accents.
- 📱 **Responsive Design** — Designed for desktop, tablet, and mobile screens.
- 💻 **Developer Introduction** — An overview of my interests and approach to development.
- 🧰 **Skills & Technologies** — A showcase of tools and technologies I am learning and using.
- 🗂️ **Project Showcase** — Project cards with category filters and detail popups.
- ⚡ **Smooth Animations** — Lightweight visual effects and transitions.
- 📬 **Contact Section** — Quick access to contact and social links.
- 🎯 **Learning-Focused** — A portfolio that grows as I build more projects.

## ⚙️ Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git (optional, for cloning the repository)

### 1. Clone the repository

```bash
git clone https://github.com/tishan-hasidu-dasanayaka/hasidu-dev-portfolio.git
```

### 2. Open the project directory

```bash
cd hasidu-dev-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to preview the portfolio.

### 5. Build for production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌐 Deployment

This project can be deployed using **Vercel**.

1. Push the project to GitHub.
2. Import the repository into [Vercel](https://vercel.com/).
3. Select **Vite** as the framework preset if it is not detected automatically.
4. Use the following build settings:

| Setting | Value |
|---|---|
| Install Command | `npm install` |
| Build Command | `npm run build` |
| Output Directory | `dist` |

5. Deploy and open the generated URL.

Every new push to the connected GitHub branch can trigger a new deployment.
